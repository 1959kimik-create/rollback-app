# Roll Back

오늘의 이동 경로와 음성 메모, 사진 및 동영상을 기록하고 날짜별로 다시 살펴보는 모바일 웹앱입니다.

## 실행

`index.html`을 정적 웹 호스팅에 배포하거나 로컬 웹 서버로 제공하세요. 위치, 카메라, 마이크 기능은 HTTPS 또는 `localhost`에서 브라우저 권한을 허용해야 사용할 수 있습니다.

## 데이터 및 브라우저 권한

- 계정 설정은 브라우저의 로컬 저장소에 저장됩니다.
- 기록은 브라우저의 IndexedDB에 저장되며, 이 저장소는 같은 브라우저와 기기에서만 사용할 수 있습니다.
- 위치 기록은 브라우저가 백그라운드 실행을 제한하면 중단될 수 있습니다.
- 경로 지도는 OpenStreetMap 타일을 인터넷으로 불러와 GPS 좌표 위에 표시합니다. API 키는 필요하지 않으며, 지도 제공을 위해 기록 위치 주변의 타일 요청이 OpenStreetMap 서버로 전송됩니다. 지도 출처는 지도 오른쪽 아래에 표시합니다.
- 장시간 경로 기록 시 Roll Back을 브라우저의 앞 화면에 계속 열어 두고, 앱을 벗어나기 전에 `저장`을 누르세요. 기록 중 화면이 꺼지지 않도록 요청하지만, 화면 잠금·다른 앱 전환·브라우저 종료 후에도 위치 기록을 계속하는 것은 보장되지 않습니다. 웹앱은 운영체제의 백그라운드 위치 서비스나 배터리 제한을 해제할 수 없습니다.
- 스마트폰에서 기록이 자주 중단되면 배터리 절약 모드를 끄고, Roll Back을 제공하는 브라우저의 배터리 사용을 제한하지 않도록 설정해 보세요. Android는 `설정 > 앱 > 브라우저 > 배터리`에서 `제한 없음` 또는 백그라운드 사용 허용을 선택하고, `설정 > 앱 > 브라우저 > 권한 > 위치`에서 위치 접근과 정확한 위치를 허용하세요. 브라우저의 사이트 설정에서도 Roll Back의 위치 권한을 허용해야 합니다. 제조사별로 메뉴 이름과 자동 실행·백그라운드 제한 설정은 다를 수 있습니다.
- iPhone/iPad에서는 `설정 > 개인정보 보호 및 보안 > 위치 서비스 > Safari 웹 사이트`에서 위치 접근을 허용하고, Safari를 앞 화면에 둔 채 기록하세요. 필요하면 `설정 > 디스플레이 및 밝기 > 자동 잠금` 시간을 늘리되, Safari 웹페이지는 화면이 잠기거나 다른 앱으로 이동한 동안 GPS 기록을 지속하도록 보장할 수 없습니다. 자동 잠금 해제는 배터리 소모를 늘릴 수 있습니다.
- 미디어 파일은 촬영·녹음이 끝나면 저장된 `RollBack` 폴더(지원되는 브라우저에서 이전에 선택한 경우) 또는 브라우저의 기본 다운로드 위치로 자동 저장을 시작합니다. 브라우저 기본 위치는 기기와 브라우저 설정에 따라 다릅니다. Android에서는 보통 브라우저의 다운로드 목록 또는 파일 앱의 Downloads에서 확인할 수 있고, iPhone/iPad에서는 Safari의 다운로드 설정에 지정된 위치에서 확인할 수 있습니다.
- 웹앱은 운영체제의 위치·마이크·카메라 권한을 대신 승인할 수 없습니다. 권한 요청은 해당 기능을 실제로 시작할 때 브라우저가 표시하며, 이미 허용된 권한은 브라우저/기기가 권한을 유지하는 동안 다시 묻지 않습니다. "매번 확인"이나 일회성 권한으로 설정된 경우에는 다시 허용해야 합니다.
- 기록의 `저장` 버튼은 경로와 미디어를 앱의 IndexedDB에 저장합니다. JSON 파일 다운로드를 자동으로 시작하지 않습니다.
- 들춰보기의 미디어 상세 화면에서 파일을 삭제하면 앱 기록에 저장된 미디어만 삭제됩니다. 이미 다운로드한 기기 파일은 별도로 삭제해야 합니다.
