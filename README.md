# Roll Back

오늘의 이동 경로와 음성 메모, 사진 및 동영상을 기록하고 날짜별로 다시 살펴보는 모바일 웹앱입니다.

## 실행

`index.html`을 정적 웹 호스팅에 배포하거나 로컬 웹 서버로 제공하세요. 위치, 카메라, 마이크 기능은 HTTPS 또는 `localhost`에서 브라우저 권한을 허용해야 사용할 수 있습니다.

## 데이터 및 브라우저 권한

- 계정 설정은 브라우저의 로컬 저장소에 저장됩니다.
- 기록은 브라우저의 IndexedDB에 저장되며, 이 저장소는 같은 브라우저와 기기에서만 사용할 수 있습니다.
- 위치 기록은 브라우저가 백그라운드 실행을 제한하면 중단될 수 있습니다.
