# Roll Back

오늘의 이동 경로와 음성 메모, 사진 및 동영상을 기록하고 날짜별로 다시 살펴보는 모바일 웹앱입니다.

## 실행

`index.html`을 정적 웹 호스팅에 배포하거나 로컬 웹 서버로 제공하세요. 위치, 카메라, 마이크 기능은 HTTPS 또는 `localhost`에서 브라우저 권한을 허용해야 사용할 수 있습니다.

## 데이터 및 브라우저 권한

- 계정 설정은 브라우저의 로컬 저장소에 저장됩니다.
- 기록은 브라우저의 IndexedDB에 저장되며, 이 저장소는 같은 브라우저와 기기에서만 사용할 수 있습니다.
- 위치 기록은 브라우저가 백그라운드 실행을 제한하면 중단될 수 있습니다.
- 로그인 후 `시작하기`를 누를 때 지원 브라우저는 다운로드 폴더 선택을 요청하고, 선택한 폴더 아래에 `RollBack` 폴더를 만들어 이후 파일을 저장합니다. 다음 실행에서는 저장된 폴더 권한을 먼저 확인하며, 저장 중 폴더 선택 창을 다시 띄우지 않습니다.
- 폴더 직접 저장을 지원하지 않는 모바일 브라우저에서는 웹앱이 `Downloads/RollBack` 폴더를 만들거나 임의 경로에 쓸 수 없습니다. 이 경우 브라우저의 기본 다운로드 기능을 사용하므로 실제 위치는 브라우저의 다운로드 설정에 따릅니다.
- 선택한 위치의 접근 권한은 브라우저가 관리합니다. 브라우저가 권한을 초기화했거나 사이트 권한이 "매번 확인"으로 설정된 경우 다시 허용해야 할 수 있습니다. 선택한 기능의 위치·마이크·카메라 권한도 `시작하기`에서 확인하며, 권한창에서 "이번에만"이 아닌 계속 허용을 선택해야 다시 묻지 않을 수 있습니다. 허용 범위와 유지 기간은 브라우저 및 기기 설정에 따라 달라집니다.
- 들춰보기의 미디어 상세 화면에서 파일을 삭제하면 앱 기록에 저장된 미디어만 삭제됩니다. 이미 다운로드한 기기 파일은 별도로 삭제해야 합니다.
